# TruthGuard 事实检察官 - 浏览器事实核验插件

> 基于腾讯云元宝搜索 (Tencent Yuanbao Search / WSA) 的全网权威多源事实穿透审校浏览器插件。

## ✨ 核心特性

1. **划词即检**：在 Chrome / Edge 等浏览器内划选任意网页文本，一键启动事实核验。
2. **轻量工作态浮窗**：页面右下角悬浮工作胶囊，实时展示当前工作状态（命题拆解、元宝搜索穿透、交叉仲裁）。
3. **全屏详细工作过程树**：点击浮窗上的 **小箭头**，立即平滑展开与网页版一致的**交互式全屏工作过程拓扑树图**，支持鼠标平移与在光标处缩放。
4. **一键查看报告**：核验完成后，浮窗自动变为「查看报告」按钮，点击弹出详细的事实审计画像与逐项辟谣档案。
5. **PDF 格式下载**：报告面板支持一键生成并下载高分辨率矢量 **PDF 格式** 审计背书报告，支持 GB/T 7714 规范引注。

## 📦 安装方法 (Chrome / Edge 浏览器)

1. 点击网页上的「下载浏览器插件」按钮，解压得到的 `truthguard-extension.zip`。
2. 打开浏览器的扩展管理页：
   - Chrome 输入：`chrome://extensions/`
   - Edge 输入：`edge://extensions/`
3. 开启右上角的 **「开发者模式」(Developer mode)**。
4. 点击 **「加载已解压的扩展程序」(Load unpacked)**，选择解压出的 `extension` 文件夹。
5. 安装完成！在任意网页选中文本即可开始体验。
