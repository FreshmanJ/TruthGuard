TruthGuard 事实检察官 隐私政策

生效日期：2026年10月 · 适用于 Chrome / Microsoft Edge 浏览器扩展

1. 概述与核心隐私承诺

TruthGuard（以下简称“我们”或“本插件”）是一款致力于帮助用户进行学术研究、技术写作与信息辨伪的事实核验副驾驶工具。我们高度尊重并保护用户的隐私权。我们不建立用户画像、不追踪用户浏览历史、不向任何第三方出售或滥用您的个人隐私数据。

2. 数据收集与使用说明

  • 本地配置数据（chrome.storage.local）：用户在插件设置面板中配置的 API Key（如腾讯元宝搜索 Key、大模型 Key）、推理模型名称及自定义代理地址，均严格存储在用户本地浏览器的隔离沙盒中。本插件不会将您的私有密钥上传至任何未经您授权的私有服务器。
  • 选中文本与核验内容：仅当您主动触发核验操作（选中文本后点击右键菜单「使用 TruthGuard 事实核验」或在插件弹窗中点击核验）时，所选文本才会作为检索与推理命题，通过安全加密链路（HTTPS）直接发送至您所配置的腾讯云元宝搜索 API 与 AI 大模型推理接口。
  • 无后台自动监听：插件绝不会在未经用户明确交互操作的情况下，自动在后台爬取、窃取或记录您在任何网页上的输入、密码、Cookies 或访问历史。

3. 浏览器权限使用说明 (Permissions Justification)

为实现核心功能，本插件在 manifest.json 中声明了以下必要权限：

  • storage：仅用于在本地持久化保存用户的偏好设置与 API 密钥。
  • contextMenus：在浏览器右键菜单中添加「使用 TruthGuard 事实核验」选项，便于快捷调起划词查证。
  • activeTab 与 scripting：当且仅当用户主动触发核验时，向当前活动标签页渲染轻量悬浮胶囊与全屏工作过程拓扑树浮窗。
  • host_permissions (<all_urls>)：允许用户在任意合规网页（学术网站、新闻资讯、技术博客等）上划选文本并调用核验接口，以及允许插件背景进程与腾讯云元宝搜索及模型 API 通信。

4. 第三方服务与链接

在核验执行期间，插件将通过安全网络协议连接至：

  • 腾讯云元宝搜索开放平台（Tencent Cloud Yuanbao Search API - api.wsa.cloud.tencent.com）用于召回互联网去噪证据。
  • 用户所选的大模型推理服务商接口（如商汤 SenseNova、OpenAI 兼容端点等）用于事实交叉比对与审计裁决。

相关第三方服务受其各自的隐私政策与服务协议约束。

5. 用户的权利与数据清除

您随时拥有对本地数据的绝对控制权：

  • 您可以在插件 Popup 弹窗的「设置」中随时清空或修改您的 API 密钥与偏好配置。
  • 在浏览器扩展管理界面中卸载本插件，将立即彻底清除本地存储的所有插件相关数据。

6. 联系我们

如果您对本隐私政策有任何疑问、意见或建议，欢迎通过 GitHub Issues 或开发者邮箱与我们取得联系。
