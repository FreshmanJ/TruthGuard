## 2. Detailed Description

```markdown
TruthGuard is an intelligent fact-checking and academic research copilot designed to detect hallucinations, verify citations, and validate factual statements directly within your browser.

Powered by Tencent Cloud Yuanbao Search (WSA) and leading LLMs, TruthGuard bridges raw internet information with rigorous multi-source cross-arbitration.

━━━━━━━━━━━━━━━━━━━━━━━━━━
🌟 Key Features
━━━━━━━━━━━━━━━━━━━━━━━━━━

🔍 【Highlight & Verify in Seconds】
Highlight any sentence or paragraph on any web page, right-click, and select "🛡️ 使用 TruthGuard 事实核验" to trigger an automated, multi-source fact-checking workflow.

⚡ 【Tencent Yuanbao Search Integration】
Access high-purity, denoised search snippets from billions of indexed pages and 150+ authoritative sources with millisecond latency, drastically reducing noise and token costs.

🌲 【Full-Screen Interactive Workflow Tree】
No black-box mystery! Watch the entire reasoning pipeline unfold in real-time through an interactive workflow topology tree:
- Proposition decomposition
- Search query extraction
- Domain recall logs & latency metrics
- Confidence scoring

🚦 【Traffic-Light Cross Arbitration】
Advanced LLMs evaluate multiple retrieved sources to produce conclusive verdicts:
- 🟢 Verified: Solid evidence backed by authoritative references.
- 🟡 Disputed / Outdated: Discrepancies found across different sources or newer versions available.
- 🔴 False / Hallucination: Identified as erroneous with direct corrective facts.

📄 【Comprehensive Audit Reports & PDF Export】
Review the complete chain of custody and evidence references. Generate and download high-resolution PDF audit reports for archival and research citation.

🔒 【Privacy-First Architecture】
All API credentials and user configurations are stored locally in your browser sandbox. TruthGuard never tracks your browsing history or sells personal data.
```
