## 2. 详细描述 (Detailed Description - 复制以下内容粘贴到商店详情)

```markdown
TruthGuard 事实检察官 —— 基于腾讯云元宝搜索 (WSA) 的学术与技术文章实时事实审校官 & 文献溯源副驾驶。

在大模型与海量网络信息时代，无论是学术论文写作、技术博客创作还是日常资讯研读，“事实幻觉”与“虚假引用”常常难以辨识。TruthGuard 结合腾讯云元宝搜索千亿级实时网页索引与垂直权威信源，为浏览器带来专业级、可追溯的事实查证与仲裁能力！

━━━━━━━━━━━━━━━━━━━━━━━━━━
🌟 核心功能亮点
━━━━━━━━━━━━━━━━━━━━━━━━━━

🔍 【网页划词，一键穿透核验】
浏览网页、学术论文或新闻时，只需鼠标选中文本，点击右键菜单「🛡️ 使用 TruthGuard 事实核验」，即可瞬间调起全网穿透式交叉核验。

⚡ 【腾讯元宝搜索原生赋能】
接入腾讯云元宝搜索 (WSA) 原生高质量去噪索引段落，毫秒级召回权威新闻、国家标准、百科论文等权威证据，告别传统网页抓取的大量噪声与广告干扰。

🌲 【全屏交互式工作过程拓扑树】
拒绝不可见的“黑盒 AI”！核验过程中，右下角轻量悬浮胶囊实时反馈状态；点击即可平滑展开全屏工作拓扑树，实时查看：
- 命题结构化拆解
- 搜索关键词生成
- 权威信源域名召回流水
- 耗时与 Token 统计

🚦 【红绿灯权威交叉仲裁与角标】
大模型智能交叉比对多方证据，给出专业判定：
- 🟢 权威证实：提供多源确凿佐证；
- 🟡 存疑/版本差异：提示时效性落后或不同信源报道差异；
- 🔴 事实错误/幻觉：明确标红并指出权威更正信息。

📄 【结构化审计报告与 PDF 导出】
核验完成后，一键呼出完整的背书审计报告，展示详细证据链条，并支持一键下载导出为高清 PDF 报告，方便存档与学术引用。

⚙️ 【高灵活度配置与隐私安全】
支持在插件 Popup 面板中自由配置元宝搜索 API Key、自定义大模型（支持 OpenAI 兼容格式、商汤 SenseNova、DeepSeek 等），所有密钥均仅保存在本地浏览器沙盒中，零隐私上传，安全合规。

━━━━━━━━━━━━━━━━━━━━━━━━━━
📖 快速上手指南
━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 安装扩展后，点击浏览器右上角 TruthGuard 图标，在「设置」中输入您的 API Key（首次体验可使用预设配置）；
2. 打开任意网页，选中有待求证的句子或段落；
3. 鼠标右键选择「🛡️ 使用 TruthGuard 事实核验」，或者直接在插件弹窗中输入文本开始快速查证；
4. 观察右下角工作胶囊，点击查看全屏过程拓扑树与最终事实仲裁审计报告！
```

## 5. 审核附注与测试指南 (Notes for Certification - 提交给微软审核员看的内容)

> 💡 **重要**：微软 Edge 审核员会阅读此项并在沙盒中实际测试插件，务必将以下说明粘贴到提交表单的 **"Notes for certification"** 栏：

```text
【Extension Overview & Purpose】
TruthGuard is a research and fact-checking copilot extension powered by Tencent Yuanbao Search (WSA) and AI LLMs. It helps researchers, students, and readers verify factual claims in text against live web search evidence.

【How to Test this Extension】
1. Install and enable the extension.
2. Open any public news, encyclopedia, or blog webpage (e.g. https://en.wikipedia.org/ or https://news.sina.com.cn/).
3. Highlight any factual claim with your mouse cursor (for example: "Python 3.12 于 2023 年正式发布").
4. Right-click the selected text and choose "🛡️ 使用 TruthGuard 事实核验" from the context menu (or click the extension action popup icon and click "立即快速核验").
5. A floating status capsule will appear at the bottom right. Click the expand button (arrow) to view the full-screen interactive workflow topology tree.
6. Once the multi-source verification completes, click "查看报告" to view the detailed verdict arbitration card, citations, and optional PDF export.

【Permissions Justification】
- "storage": Used solely for persisting user preferences, local custom API credentials, and options within the browser's local sandbox.
- "contextMenus": Adds a convenient right-click shortcut on text selections to trigger fact-checking.
- "activeTab" & "scripting": Allows the extension to safely inject the lightweight floating progress capsule and workflow inspection modal onto the user's active page when the user initiates a verification action.
- "<all_urls>": Required so that users can fact-check statements across any legitimate online articles/websites, and enables the background service worker to fetch search evidence from Tencent Cloud WSA API and LLM inference endpoints.

【Test API Credentials】
The extension includes pre-configured sandbox demo credentials out of the box in the background service worker, so reviewers can immediately trigger and verify the workflow without additional setup. If you wish to test custom keys, you can open the extension popup -> Settings -> enter your custom keys and click Save.
```
