# 微软 Edge 商店屏幕截图拍摄指南 (Screenshot Guide)

微软 Edge 扩展商店（Microsoft Edge Partner Center）对截图的要求：
* **数量要求**：至少上传 1 张（**强烈推荐上传 3 ~ 4 张**，展示完整工作流以增加审核通过率和用户下载转化率）。
* **分辨率尺寸**：**1280 x 800 像素**（16:10 推荐尺寸）或 640 x 480 像素。
* **文件格式**：PNG 或 JPEG，单个文件小于 2MB。

## 🛠️ 如何用 Edge 开发者工具精准截取 1280 x 800 截图？

无需第三方复杂修图软件，在 Edge 浏览器中即可 1 秒截出标准尺寸图：

1. 打开 Edge 浏览器，按 `F12` 打开**开发者工具**。
2. 点击开发者工具左上角的 **「切换设备仿真」** 图标（快捷键 `Ctrl + Shift + M`）。
3. 在顶部的尺寸输入框中，将宽度设为 `1280`，高度设为 `800`（缩放比例设为 100%）。
4. 在页面上操作 TruthGuard（划词或打开工作树/报告）。
5. 点击设备工具栏最右侧的三个点菜单 `···`，选择 **「捕获屏幕截图 (Capture screenshot)」**。
6. Edge 会自动下载一张完美的 `1280 x 800` PNG 图像，直接用于上传！
